# Snake: Apex Predators (React)

A high-performance AI Snake simulation built with React and HTML5 Canvas.

## 🚀 Commit Instructions
**CRITICAL:** Always commit your changes to this repository immediately after making any updates. This ensures the standalone backup is synced and prevents history fragmentation.

## Features
- Multi-snake ecosystem (up to 6 predators).
- Configurable AI Sight and Smell ranges.
- Real-time simulation speed control.
- Fully mobile-responsive glassmorphic UI.

## Getting Started
1. `npm install`
2. `npm start`
